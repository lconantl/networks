# Веб-сервер: архитектура

Статический HTTP/1.1-сервер на C++20 под Linux: отдаёт файлы из папки сайта на запросы GET и HEAD.
Один файл `webserver.cpp`, три режима работы, выбор режима — пошаговым меню при запуске.

## Режимы

| Режим            | Как устроен                                                                                                                                         | Уровень |
|------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|---------|
| Последовательный | `poll` ждёт клиента или сигнал, затем клиент обслуживается целиком                                                                                  | базовый |
| Многопоточный    | на каждое соединение `std::thread`; потоки учитывает `WorkerRegistry` и присоединяет (`join`) после завершения; больше 512 одновременно — ответ 503 | +1      |
| Асинхронный      | один поток, `epoll` в level-triggered режиме, неблокирующие сокеты, до 10 000 соединений                                                            | +2      |

## Сборка и запуск (WSL / Linux)

```bash
sudo apt install -y build-essential cmake git
cmake -S . -B build && cmake --build build -j
./webserver
```

В меню выберите режим, затем Enter на остальных вопросах (порт 8080, папка `www`).
Откройте в браузере Windows `http://localhost:8080/` — WSL пробрасывает localhost сам.
