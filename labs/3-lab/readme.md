# SMTP Client — лабораторная работа

Консольный SMTP-клиент на C++20. Подключается к почтовому серверу через TCP-сокет, проводит
SMTP-диалог по RFC 5321 и отправляет письмо.

Примеры реальных сессий — в [docs/examples.md](docs/examples.md).

| Уровень   | Что сделано                                                                                                                                                                |
|-----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Базовый   | `socket()`, `connect()`, `read()`, `write()`, `close()`; 220 → EHLO/HELO → MAIL FROM → RCPT TO → DATA → тело → `.` → QUIT; проверка кодов 220/250/354/221; RAII для сокета |
| +1 (TLS)  | STARTTLS (порт 587) и неявный TLS (465) на OpenSSL, проверка сертификата и имени хоста, AUTH PLAIN и AUTH LOGIN (RFC 4954, ранее RFC 2554)                                 |
| +2 (MIME) | `multipart/mixed`, base64, несколько вложений, Content-Type по расширению, русские темы (RFC 2047) и имена файлов (RFC 2231), потоковая отправка больших файлов            |

## Быстрый старт

```
pip install -r tools/requirements.txt
python tools/smtp_server.py
```

Во втором окне запустите `smtp-client` и нажимайте Enter на каждом вопросе — письмо уйдёт на
локальный сервер, а он покажет его и сохранит в `inbox/*.eml`.

## Запуск

Программа запускается без аргументов и задаёт вопросы:

1. **Куда отправляем** — локальный сервер, Яндекс, Mail.ru, Gmail или свой сервер
   (адрес, шифрование, порт, проверка сертификата, нужна ли авторизация).
2. **Логин и пароль** — для публичных серверов.
3. **От кого, кому** (несколько адресов через запятую), **тема**, **текст** (из консоли с
   `\n` для переноса строки или из файла).
4. **Что ещё добавить**: Cc, Bcc, вложения, сохранить письмо в `.eml`, записать лог в файл.
5. **Как показывать диалог** — полностью (`S:`/`C:`) или только итог.
6. **Отправить?**

Управление: ↑/↓ — курсор, 1–9 — выбрать пункт, Пробел — отметить, Enter — подтвердить
(без отметки — вариант по умолчанию), Esc — выход.

Пути к вложениям можно вставлять прямо из «Копировать как путь» в Проводнике — кавычки
убираются автоматически.

На Windows запускайте в Windows Terminal или cmd. Во встроенной консоли CLion включите
Run Configuration → «Emulate terminal in the output console», иначе стрелки не работают.

### Публичные серверы

| Сервер         | Порт | Шифрование | Пароль                                                                      |
|----------------|------|------------|-----------------------------------------------------------------------------|
| smtp.yandex.ru | 587  | STARTTLS   | пароль приложения: id.yandex.ru → Безопасность → Пароли приложений          |
| smtp.mail.ru   | 465  | TLS        | пароль приложения: Настройки → Безопасность → Пароли для внешних приложений |
| smtp.gmail.com | 587  | STARTTLS   | пароль приложения (нужна двухфакторная аутентификация)                      |

Обычный пароль от почты эти серверы не принимают — будет ошибка 535.

Порт 25 для отправки на публичные серверы часто заблокирован провайдером, а без AUTH сервер
принимает письма только для своих ящиков. Для базовой части лабы удобнее локальный сервер.

## Тестовый сервер

`tools/smtp_server.py` — SMTP-сервер на [aiosmtpd](https://aiosmtpd.aio-libs.org/)
Печатает каждое письмо (отправитель, получатели, тема, текст, вложения) и сохраняет его в `inbox/`.

```
python tools/smtp_server.py                       # 127.0.0.1:2525, без TLS и AUTH
python tools/make_test_cert.py                    # создать cert.pem и key.pem
python tools/smtp_server.py --port 2526 --cert cert.pem --key key.pem --auth user:secret
```

Во втором режиме сервер требует STARTTLS и авторизацию. В клиенте выберите «Другой сервер»,
`localhost`, STARTTLS, порт 2526, «Проверять сертификат — Нет» (сертификат самоподписанный).
