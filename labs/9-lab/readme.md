# HTTP Web Proxy — лабораторная работа №14

HTTP-прокси с кэшированием на диск. Базовый уровень задания, без
дополнительных баллов (без многопоточности, без POST, без валидации
свежести кэша).

## Сборка (WSL / Linux)

```bash
cd networks/labs/9-lab
cmake -S . -B build
cmake --build build -j
```

## Запуск

```bash
./proxy_server [port] # по умолчанию порт 8888
```

Проверка без настройки браузера:

```bash
curl -x http://127.0.0.1:8888 http://example.com/
curl -x http://127.0.0.1:8888 http://example.com/  # второй раз — кэш-попадание
```

Либо указать прокси `127.0.0.1:8888` вручную в настройках браузера и
открыть любой `http://` (не `https://`) адрес.

## Ограничения

- Только HTTP (без `CONNECT`/HTTPS) и только метод `GET`.
- Ответ буферизуется в памяти целиком перед пересылкой — для очень
  больших файлов это неэффективно.
- Кэш не инвалидируется по времени: если страница на сервере изменилась,
  старую версию нужно удалить из `cache/` вручную.
