# UDP Pinger — лабораторная работа №13

UDP-клиент и сервер для измерения RTT и потерь пакетов по аналогии с
утилитой `ping`. Базовый уровень задания, без дополнительных баллов
(без агрегированной статистики и без UDP Heartbeat).

## Как это работает

Клиент отправляет серверу 10 датаграмм вида `Ping <seq> <timestamp_ms>` и
на каждую ждёт ответ не дольше 1 секунды (`setsockopt(SO_RCVTIMEO)`).
Время отправки запоминается через `gettimeofday()` до вызова `sendto()`;
RTT — это разница между временем прихода ответа и временем отправки.
Если `recvfrom()` возвращает ошибку по тайм-ауту (`EAGAIN`/`EWOULDBLOCK`),
клиент печатает `Request timed out` и переходит к следующему пакету.

Сервер получает датаграмму и с вероятностью 30% молча её отбрасывает —
это эмулирует потери в сети. Остальные пакеты отправляются клиенту
обратно без изменений (echo).

## Сборка (WSL / Linux)

```bash
cd networks/labs/8-lab
cmake -S . -B build
cmake --build build -j
```

## Запуск

```bash
./udp_pinger_server [port] # по умолчанию порт 12000
./udp_pinger_client <server_ip> [port]
```

Пример вывода клиента:

```
Ответ от сервера: PING 1 1699999999999, RTT = 0.021 сек
Request timed out
Ответ от сервера: PING 3 1699999999999, RTT = 0.019 сек
...
```
